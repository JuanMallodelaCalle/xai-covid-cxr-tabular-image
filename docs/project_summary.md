# Project Summary

## Title

Explainable AI on COVID-19 Chest X-Ray Tabular and Image Data

## Context

This project was developed for the Large-Scale Media Analytics course at Universidad Politécnica de Madrid.

The objective was to explore explainable AI methods on a heterogeneous public COVID-19 chest X-ray dataset combining image data, patient metadata, and clinical notes.

## Core Contributions

- Cleaned and structured a heterogeneous medical imaging dataset.
- Performed exploratory analysis at image and patient level.
- Created a manual artifact annotation file to identify potential visual shortcuts.
- Built tabular classification baselines using Random Forest and XGBoost.
- Added TF-IDF features from cleaned clinical notes.
- Trained a simple CNN baseline for image classification.
- Applied SHAP, LIME, feature importance, and Grad-CAM for interpretability.
- Reviewed external open-source chest X-ray models and pretrained tools for context.

## Portfolio Positioning

This repository is best understood as a bias-aware explainable AI case study for medical imaging data, not as a clinical diagnostic system.

It demonstrates practical experience with:

- medical data preprocessing;
- tabular and image ML pipelines;
- model interpretability;
- dataset bias analysis;
- responsible framing of AI systems in healthcare contexts.
